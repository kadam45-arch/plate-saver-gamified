# Eco-Mess Dashboard

Create a premium gamified dashboard called Eco-Mess for college mess food wastage.

Design Style: 

- Use Linear App + Apple + Zomato inspired UI. NO full green background.

- Base color: Charcoal black #0A0A0B with glassmorphism.

- Cards should have soft inner border, big 24px border radius, and subtle shadows.

- Use Inter font.

Sections to build from my existing code (keep same data and logic):

1.  Top Header with Eco-Mess logo and user Yash Kadam CSE

2.  Hero Stats (3 cards): 

    - Card 1: Total Eco-Points: 1250, streak 12 days. Make it white-ish premium card with glow.

    - Card 2: Level 5 Green Guardian with XP bar 750/1000

    - Card 3: Impact: 8.2kg Food Saved, 12.5kg CO2 Avoided with bluish gradient.

3.  How to Earn Points (3 cards) - VERY IMPORTANT: Use REAL images from unsplash for each:

    - Accurate Meal Booking (use image of person booking on phone)

    - Finish Your Plate (use image of empty clean plate)

    - Join Redistribution (use image of food donation/volunteers)

    On click, add points. Add hover zoom effect on images.

4.  Leaderboard and Rewards Store and Weekly Bar Chart.

Make it look expensive, minimal, and ready for college presentation. Add motion animations with framer-motion.

Use Tailwind CSS, Next.js App Router, lucide-react icons.
